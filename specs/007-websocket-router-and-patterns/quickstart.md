# Quickstart: Generic WebSocket API

**Feature**: Hook-Based Multi-Channel WebSocket Router with Example Component
**Date**: 2025-10-23
**Last Updated**: 2025-10-29
**Purpose**: Validate implementation matches specification

## Component Overview

The example component demonstrates multi-channel WebSocket architecture with three channels:

- **Coffee Channel** (`/ws/example/v1/coffee`): Request/response pattern that converts input text to coffee-related words
- **Chat Channel** (`/ws/example/v1/chat`): Bidirectional communication with uppercase echo and server-initiated random messages every 3 seconds
- **Agent-Events Channel** (`/ws/example/v1/agent_events`): Subscription-based event streaming with dynamic subscription management for log and progress event groups

## Prerequisites

1. **Services Running**:

### Test Scenario 1: Coffee Channel - Send Request

**Objective**: Verify client can connect to coffee channel and send coffee word generation requests.

### Steps

1. **Connect to Coffee WebSocket endpoint**:
   ```bash
   websocat "ws://localhost:8000/ws/example/v1/coffee"
   ```

**Validation**:

- [ ] Response output contains coffee words: "h" → "espresso", "i" → "hario"

## Python Test Client Example

For automated testing, use this Python client:

```python
import asyncio
import json
from websockets import connect

async def test_coffee_endpoint():
    """Test coffee WebSocket endpoint."""
    uri = "ws://localhost:8000/ws/example/v1/coffee"

    async with connect(uri) as websocket:
        # Test Case 1: Valid request
        await websocket.send(json.dumps({"input": "hi"}))
        response = await websocket.recv()
        data = json.loads(response)
        assert "output" in data
        assert "espresso" in data["output"]
        assert "hario" in data["output"]
        print(f"✓ Test 1 passed: {data}")

        # Test Case 2: Multiple requests
        await websocket.send(json.dumps({"input": "go"}))
        response = await websocket.recv()
        data = json.loads(response)
        assert "output" in data
        assert "grande" in data["output"]
        assert "origin" in data["output"]
        print(f"✓ Test 2 passed: {data}")

        # Test Case 3: Invalid request (missing input)
        await websocket.send(json.dumps({}))
        response = await websocket.recv()
        data = json.loads(response)
        assert data["error"] == "VALIDATION_ERROR"
        print(f"✓ Test 3 passed: {data}")

        # Test Case 4: Still works after error
        await websocket.send(json.dumps({"input": "tea"}))
        response = await websocket.recv()
        data = json.loads(response)
        assert "output" in data
        print(f"✓ Test 4 passed: {data}")

    print("\n✓ All tests passed!")

if __name__ == "__main__":
    asyncio.run(test_coffee_endpoint())
```

**Save as**: `examples/websocket_coffee_test.py`

**Run with**:
```bash
uv run python examples/websocket_coffee_test.py
```

## JavaScript Test Client Example

For browser or Node.js testing:

```javascript
// test_websocket.js
const WebSocket = require('ws');

async function testCoffeeEndpoint() {
    const ws = new WebSocket('ws://localhost:8000/ws/example/v1/coffee');

    ws.on('open', () => {
        console.log('✓ Connection established');

        // Test 1: Valid request
        ws.send(JSON.stringify({ input: 'hi' }));
    });

    let testNumber = 1;
    ws.on('message', (data) => {
        const response = JSON.parse(data);
        console.log(`Response ${testNumber}:`, response);

        if (testNumber === 1) {
            // Test 2: Second request
            ws.send(JSON.stringify({ input: 'go' }));
            testNumber++;
        } else if (testNumber === 2) {
            // Test 3: Invalid request
            ws.send(JSON.stringify({}));
            testNumber++;
        } else if (testNumber === 3) {
            // All tests done
            console.log('\n✓ All tests passed!');
            ws.close();
        }
    });

    ws.on('error', (error) => {
        console.error('✗ Error:', error);
    });

    ws.on('close', () => {
        console.log('✓ Connection closed');
    });
}

testCoffeeEndpoint();
```

**Run with**:
```bash
node test_websocket.js
```

## Troubleshooting

### Issue: Connection Refused

**Cause**: Nexus API not running or wrong port

**Solution**:
```bash
# Check if service is running
ps aux | grep "nexus.main"

# Check correct port
curl http://localhost:8000/health
```

### Issue: WebSocket Upgrade Failed

**Cause**: FastAPI WebSocket support not configured

**Solution**:
```bash
# Verify FastAPI installation
uv run python -c "from fastapi import WebSocket; print('OK')"

# Check server logs for errors
```

### Issue: No Response Received

**Cause**: Message handler not processing requests

**Solution**:
```bash
# Check server logs for errors
# Verify message format is correct JSON
# Test with simple curl first: curl http://localhost:8000/health
```

### Issue: High Latency

**Cause**: Server overload or network issues

**Solution**:
```bash
# Check server resource usage
top -p $(pgrep -f "nexus.main")

# Test latency with ping
ping localhost
```
