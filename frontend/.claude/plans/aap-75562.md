# AAP-75562 — Users → Identities tab: table columns

## Domain terms resolved

**Connected identity** — A `UserIdentityRead` record; a provider the user has linked. Returned by `GET /users/{user_id}/identities`. Issuer URL = `identity.issuer`.

**Unlinked provider** — An `AuthProvider` that exists in the system but is not linked by this user. Derived by diffing the full provider list against linked identities. Issuer URL = `provider.configuration.issuer_url` (from `identityProvidersClient`).

**Issuer URL** — The OIDC `iss` claim. Same concept whether from a connected identity or an unlinked provider.

## Decisions

| #   | Question                           | Decision                                                                                                                                         |
| --- | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Issuer URL for unlinked rows       | Fetch full provider data via `identityProvidersClient.useQuery('/identity_providers/')` — one request, TanStack Query cached                     |
| 2   | Expandable rows                    | Remove entirely — not in acceptance criteria                                                                                                     |
| 3   | Unified list vs two-section layout | Merge into a single unified list (discriminated union); render as flat `<Tbody><Tr>` — removing expand rows makes two-section layout unnecessary |
| 4   | Column order                       | `Provider → Status → Issuer URL → Linked → Last authenticated → Actions` (matches designer intent)                                               |

## Acceptance criteria

- Status column: "Connected" green filled Label, "Not connected" gray filled Label
- Issuer URL column: matches Identity Providers table format (`<Truncate>`)
- Linked column: `formatDateTime(created_at)` for connected; `-` for unconnected
- Last authenticated: `formatDateTime(last_used_at)` or `-` for both row types
- Default sort: Status ascending (Connected first)

## Implementation notes

- Discriminated union: `{ kind: 'connected'; identity: UserIdentity } | { kind: 'disconnected'; provider: AuthProvider; issuerUrl: string }`
- Join unlinked providers with `identityProvidersClient` data on `provider.id === idp.id` to get `issuer_url`
- `getIdentitySortKey` needs a new case for sort index 1 (Status) — sort key: `'0'` for connected, `'1'` for disconnected (so ascending = Connected first)
- Remove `isExpandable` from `ScrollableTableContainer`
- `colSpan` on any spanning cells needs updating (5 → 6, accounting for new columns)
- Update `useTableSort` initial sort index to 1 (Status column)
